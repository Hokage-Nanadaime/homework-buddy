# Contributing

Thank you for looking. The project is created by Hokage-Nanadaime, built together with Claude (Anthropic). The code is open source (MIT), and the owner reviews and merges every change; nobody else can push.

- Open an issue first for anything larger than a small fix, so effort is not wasted.
- Keep changes small and tested: `npm run typecheck`, `npm test` and `npm run build` must pass.
- **Never add copyrighted material**: no school-book text or exercises, exam papers, page photos, or anything you did not write. Content for a real book belongs in a private copy (see `docs/BOOK_PIPELINE.md`), not here.
- **Never add personal data**: no children's names, photos, school names, emails, phone numbers or tokens.
- Use British spelling in the app's wording, plain words for children, and the existing shared pieces before writing new ones.

Security problems: do not open a public issue; see `SECURITY.md`.
